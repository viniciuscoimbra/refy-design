# Primeiro projeto com Refy

Copie esta pasta para fora do repositório e instale o pacote da versão publicada:

```bash
npm install @refy-design/web
npm run build
npm run dev
```

O projeto usa a API pública, CSS do pacote e `theme.json` exportado do editor real. Substitua esse JSON pelo seu tema. O roteiro completo de temas está em `docs/THEMING.md` do repositório refy.
