# Support

[Português](docs/pt-BR/SUPPORT.md) · [Español](docs/es/SUPPORT.md)

| You need | Where |
|---|---|
| To learn how to use a component, a theme or the MCP server | [refy.design/en/docs](https://refy.design/en/docs) |
| To report a bug | [New issue](https://github.com/viniciuscoimbra/refy-design/issues/new/choose), **Bug report** |
| A prop, token or component that refy does not have | [New issue](https://github.com/viniciuscoimbra/refy-design/issues/new/choose), **Missing in refy** |
| To report a security improvement | Repository **Security** tab, **Report a vulnerability** ([SECURITY.md](SECURITY.md)) |
| To contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

Maintainers answer issues in English, Portuguese and Spanish.
