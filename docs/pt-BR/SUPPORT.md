# Suporte

[English](../../SUPPORT.md) · [Español](../es/SUPPORT.md)

| Você precisa | Onde |
|---|---|
| Aprender a usar um componente, um tema ou o servidor MCP | [refy.design/docs](https://refy.design/docs) |
| Relatar um defeito | [Nova issue](https://github.com/viniciuscoimbra/refy-design/issues/new/choose), **Bug report** |
| Uma prop, um token ou um componente que o refy não tem | [Nova issue](https://github.com/viniciuscoimbra/refy-design/issues/new/choose), **Missing in refy** |
| Relatar uma melhoria de segurança | Aba **Security** do repositório, **Report a vulnerability** ([SECURITY.md](SECURITY.md)) |
| Contribuir com código | [CONTRIBUTING.md](CONTRIBUTING.md) |

Os mantenedores respondem issues em português, inglês e espanhol.
