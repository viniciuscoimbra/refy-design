# Soporte

[English](../../SUPPORT.md) · [Português](../pt-BR/SUPPORT.md)

| Necesitas | Dónde |
|---|---|
| Aprender a usar un componente, un tema o el servidor MCP | [refy.design/es/docs](https://refy.design/es/docs) |
| Reportar un defecto | [Nuevo issue](https://github.com/viniciuscoimbra/refy-design/issues/new/choose), **Bug report** |
| Una prop, un token o un componente que refy no tiene | [Nuevo issue](https://github.com/viniciuscoimbra/refy-design/issues/new/choose), **Missing in refy** |
| Reportar una mejora de seguridad | Pestaña **Security** del repositorio, **Report a vulnerability** ([SECURITY.md](SECURITY.md)) |
| Contribuir con código | [CONTRIBUTING.md](CONTRIBUTING.md) |

Los mantenedores responden issues en español, inglés y portugués.
