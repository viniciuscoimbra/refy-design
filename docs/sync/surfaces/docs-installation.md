Como instalar o pacote web e o mobile e começar um projeto. Só em português; o site traduz em Docs > Instalação.

| Afirmação | Fonte |
|---|---|
| Nome e versão dos pacotes | `package.json` e `packages/native/package.json` |
| O que o mobile tem e não tem | `src/catalog/native-parity.json` e `packages/native/DIVERGENCIAS.md` |
| Medições (kB, componentes testados) | seção "Medido": registro de uma rodada, com data quando houver |

Como atualizar: não prometa no mobile recurso que a versão publicada não tem; comando de instalação usa o nome do pacote.
